# RABOT

<img src="docs/assets/logo.jpg" alt="RABOT" width="480">

予定の管理・通知を行う LINE Bot

## コンセプト

日常の「ちょっと面倒」を少しでも減らし、みんなの時間を効率的に。
学生生活を便利にすることを目指して、仲間とともに5年間開発・運用・改善を続けてきたプロジェクトです。

## 機能

- **課題管理** — クラスで出された課題の一覧・詳細を LINE で確認
- **スケジュール表示** — 授業・試験の予定を表示
- **バス通知** — 現在時刻に合わせてバスの発車時刻を自動でお知らせ
- **リマインダー・プッシュ通知** — Google カレンダーと連携して予定を通知

## 仕組み

- Google Apps Script(GAS)製。スプレッドシートをデータベースとして管理し、簡単に編集・更新できる柔軟な構成
- LINE からのメッセージをトリガーに、必要な情報を自動で取得・整形して返信
- `docs/` はリマインダー追加・設定・統計用の Web サイト(GitHub Pages)
